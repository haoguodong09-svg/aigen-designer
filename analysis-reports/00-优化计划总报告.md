## 0. 一页摘要

**问题**：在画布上绘制多个表单元素后，"多元素之间如何绑定事件 / 关联 / 计算"几乎没有可视化入口——唯一入口是右侧"事件"面板里逐事件点「+」，弹出一个 1200px 的开发式弹窗（组件树 + 方法列表 + 参数 JSON），生命周期事件直接暴露 Vue 术语（vnodeMounted / vnodeErrorCaptured…），跨元素逻辑（求和、显隐联动、禁用联动）必须手写整页 JS 脚本并用硬编码组件 id（find('1').getValue()）。用户"一头雾水"是**结构性体验缺陷**，不是文案问题。

**根因（证据充分）**：绑定数据只存在于 schema.on，画布元素上零标记；动作配置弹窗是开发工具布局；无"目标组件"点选交互；表达式引擎（FormulaEngine）、事件总线（createEventBus）、字段状态（FieldState）等底层能力**运行时已就绪，但全部没有设计态 UI**。

**方案**：三层递进——(1) 画布层：绑定角标（⚡N）+ "关联模式"三步点选（源→目标→快速关联气泡），不做连线图；(2) 面板层："事件"改"行为"，业务化命名 + 动作卡片摘要/启停用/搜索/空状态模板；1200px 弹窗改为 720px 四步向导抽屉（类型→目标→方法→参数），目标组件支持**画布点选 + 树 + 搜索**三种方式，参数区内置表达式插入器（直接产出运行时已支持的 **isExpression**，**零运行时改动**）；(3) 新增"关联与计算"面板：字段联动规则（当 X=值 → 显示/隐藏/禁用/赋值）+ 计算字段 + 事件总线，采用"设计态视图模型 → 编译到 on"双写策略，复用现有运行时。

**落地**：三阶段。P1 纯 UI 重构事件面板与动作配置（不动运行时，风险最低）；P2 画布关联模式与可视化标记（只读叠加）；P3 联动/计算/事件总线模块 + 运行时增强（唯一触碰 doActions 的阶段，全部新字段可选 + fail-safe）。

## 3. 竞品洞察（可借鉴 Top 3，详见子报告 03）

1. **保留"事件-动作列表"骨架，重做表达层**（amis / Retool / Appsmith 同范式）：底层 on + 动作列表本身合理，只需给动作条目加图标、"仅当…"条件、启用开关，生命周期用人话命名替换 vnode\* 术语——**运行时零改动**。
2. **"先选目标组件 → 自动枚举其方法"**（Retool Control component 模式）：取代"组件树 + 全量方法列表"，配画布点选高亮，心智负担减半。
3. **三层能力模型：快速联动规则 → 事件-动作 → JS 兜底**（钉钉宜搭式业务规则层 + Formily 声明式联动 + 脚本折叠兜底）：高频诉求（当 X=值 → 隐藏/禁用/赋值）用规则表单，规则预编译为 on 事件，不破坏现有运行时；复杂逻辑仍走自定义函数但折叠进"高级"。

**不建议照搬**：纯连线图（表单场景面条复杂度，无主流产品采用）、LowCodeEngine 式纯代码块绑定（业务用户门槛过高）、无升级通道的简单 value→状态规则。

## 4. 优化目标与设计原则（子报告 04 完整版）

**目标**：30 秒内完成第一个绑定；画布上"看得见谁有绑定、谁影响谁"；从"绑定"升级为"行为流"；所有能力分级渐进披露。

1. **业务语言优先**：事件叫"值变化时"而非 change，生命周期叫"页面加载完成"而非 aigenReady；技术名仅"高级/源码"模式展示。
2. **画布即真相**：画布元素是事件/关联的第一入口与可视化载体（角标、高亮、点选），侧边栏负责细节，双向同步。
3. **从"绑定"到"行为流"**：界面按 事件(When) → 动作链(Then) 组织，动作摘要用句子呈现（"把『金额』设置为 数量×单价"），而非方法名堆砌。
4. **渐进披露**：默认只暴露高频能力（赋值、显隐、禁用、调用方法）；脚本/条件/延迟/表达式折叠进"更多/高级"。
5. **每一步可预览、可撤销、可安全返回**：沿用 isDesignMode 约定；所有写入走 revoke 栈；删除/停用不丢数据。

## 5. 交互重构方案（分层设计，完整 ASCII 草图见子报告 04）

### 5.1 画布层（P2 重点）

- **状态角标 EventBadge**（nodeItem.vue 外套叠加层，仅设计态渲染）：⚡N（绑定了 N 个动作）、链N（参与 N 条联动规则）、灰 ⚡（全部动作停用）；hover 显示人话摘要，点击切到"行为"面板并展开对应分组。
- **关联模式 Link Mode**（三处等价入口：工具栏"关联"按钮 / 右键菜单"建立关联…" / 行为面板向导第 2 步）：点源元素 → 点目标元素 → 弹出快速关联气泡（值联动 / 显示隐藏 / 禁用 / 自定义事件…）；Esc 或点空白退出；关联模式下禁用画布拖拽。**不画连线**（理由见"不做清单"）。
- **右键菜单增项**：绑定事件… / 建立关联… / 查看已绑定行为（现有 contextMenu 是注入扩展点，本方案提供内置默认实现）。
- **多选（P2 尾期）**：Shift+点击追加选中（designer state 增加 selectedNodes），批量仅开放"安全动作集"（setValue/setAttr/启停用/删除）。

### 5.2 "行为"面板层（P1 重点，替代现有"事件"面板）

- 侧边栏"事件"更名"行为"；事件分组业务化命名 + 一句解释。
- 动作卡片升级：人话摘要（新组件 ActionSummary）、启停用、编辑/复制/删除、拖拽排序（保留）+ 上下按钮、搜索、空状态引导模板（"点击时显示/隐藏其他元素""值变化时计算合计"→ 点击直达向导预填）。
- 事件级启停用开关。

### 5.3 动作配置层（P1 重点，替代 1200px 弹窗）

- **720px 右侧向导抽屉**，四步：1 动作类型 → 2 目标组件 → 3 动作方法 → 4 参数配置，步骤可回跳打勾。
- Step2 目标组件三种方式 Tab：**画布点选（默认，抽屉期间画布元素可 hover 高亮点击）/ 组件树 / 搜索**（复用 nodes.vue:40-74 getNodeSchema 逻辑）。
- Step3 方法列表带说明与搜索（"设置值 setValue —— 将目标元素的值设为指定内容"）。
- Step4 参数表单化 + **表达式插入器 ExpressionInsert**：左列字段/函数库，中列公式编辑，右列实时预览；产出 {"**isExpression**":true,...} —— **与运行时 doActions 现有支持完全对齐，零运行时改动**。
- setAttr 快捷参数改为从 config.attribute 过滤 props.\* 的下拉（迁移现有硬编码逻辑 aigenActionModal:154-191）。

### 5.4 新增"关联与计算"面板（P3，id: link_view，registerRightSidebar 注册）

- **字段联动**：规则列表（"当『支付方式』= 转账 → 显示『银行账号』"），新建/编辑表单：源字段 + 触发时机 + 条件（可选）+ 目标元素 + 行为（显示/隐藏/禁用/赋值/清空）+ 赋值内容（常量/字段引用/公式）。
- **计算字段**：目标元素 + 公式编辑区（复用表达式插入器），依赖字段自动解析，实时预览。
- **事件总线视图**：页面内自定义事件一览，A 广播 → B 监听响应（复用 createEventBus('root')）。
- **关键决策——双写策略**：设计态视图模型 schema.links（结构化元数据）驱动面板；保存时**编译到 on[change] 的 ActionsModel**，运行时复用 doActions，**不新增运行时机制**；旧数据无 links 时从 on 反解析。

### 5.5 生命周期人话化命名表（P1 落文案，P3 全量）

| 旧技术名 | 新名称 | 触发时机 | 典型用途 |
| --- | --- | --- | --- |
| aigenReady | 页面加载完成 | 全部组件渲染完成后一次 | 初始化默认值、拉取首屏数据 |
| vnodeMounted | 组件挂载完成 | 本组件首次渲染后 | 组件自身初始化、加载选项 |
| vnodeBeforeMount | 组件挂载前 | 渲染前一刻 | 预置初始属性 |
| vnodeUpdated | 组件更新完成 | 属性/数据更新后 | 更新后刷新合计 |
| vnodeBeforeUpdate | 组件更新前 | 更新前一刻 | 记录旧值、拦截更新 |
| vnodeUnmounted | 组件卸载完成 | 从页面移除后 | 清理定时器 |
| vnodeBeforeUnmount | 组件卸载前 | 移除之前 | 释放资源、确认离开 |
| vnodeErrorCaptured | 组件错误捕获 | 渲染/运行出错时 | 错误提示、降级显示 |

落地：event.vue 的 LIFECYCLE_EVENTS 硬编码替换为带 businessName/group/trigger/usage 元数据的常量表；组件事件（config.event）支持可选 businessName 字段。

## 6. 数据模型演进（P1 只加字段不生效，P3 运行时生效）

```ts
// ActionsModel 新增字段（全部可选，读取层 normalizeAction 归一化，兼容旧数据）
interface ActionsModel {
  id?: string;              // 稳定身份：拖拽 key/复制/条件引用（旧数据缺省，读取层补 UUID）
  name?: string;            // 动作命名（人话，用于摘要/搜索）
  remark?: string;          // 备注
  enabled?: boolean;        // 启停用，缺省 true
  group?: string;           // 动作分组（行为流叙事）
  delay?: number;           // 延迟执行毫秒数（P3 运行时）
  condition?: ConditionGroup; // 条件 DSL（纯 JSON，不存函数）
  type: 'component' | 'custom' | 'public';
  componentId?: string | null;
  methodName: string;
  args?: string;            // JSON 数组字符串，元素可为 { __isExpression__, content }
}

// PageSchema 新增（可选）
computed?: ComputedField[];      // 计算字段定义（P3 页面级求值器）
vars?: Record<string, unknown>;  // 全局状态初值（P3）
// schema.links: FieldLink[]     // 设计态联动视图模型（P3，编译到 on）
```

兼容策略：写入层保持 on 结构不变；读取层归一化（补 id/enabled 默认值）；不迁移、不重写旧 schema；doActions 对 enabled/delay/condition 全部 fail-safe（延续"单动作异常不中断链"约定 pageManager.ts:274-287）。

## 7. 分阶段实施计划

### P1 · 事件面板与动作配置体验重构（纯 UI，不动运行时，建议 2-3 周）

- **目标**：消灭"看不懂、不知道能做什么"；表达式插入器直接复用 doActions 已有分支，**运行时零改动**。
- **涉及文件**：event.vue（生命周期命名表/分组文案/空状态）；AigenActionEditor/\*（动作摘要/启停用/复制/搜索）；新增 AigenActionDrawer/（index + 4 个 Step 组件）、ExpressionInsert/、ActionSummary/；aigenActionModal 迁移为抽屉底层（aigenArgsEditor/aigenScriptEdit 保留复用）；types（ActionsModel 可选字段）；utils 新增 normalizeAction.ts；docs/guide/extensions/component.md。
- **验收**：旧 schema 打开无告警无重写；向导 4 步完成增/改/复制/停用，步骤可回跳；空状态模板 30 秒产出第一个绑定；表达式插入器在"预览"中正确求值；设计态不触发任何事件（回归 isDesignMode）；1200px 弹窗下线。
- **风险**：抽屉替换弹窗的布局回归（步骤 2 画布点选与 canvasScale 坐标换算单独测试）；动作 id 缺失由读取层兜底。

### P2 · 画布关联模式与可视化标记（只读叠加，建议 2 周）

- **目标**：画布可见、可点选、可理解。
- **涉及文件**：新增 EventBadge.vue、QuickLinkPopover.vue、composable useLinkMode.ts（模式状态机 idle→select-source→select-target→linking）；nodes.vue/nodeItem.vue（角标叠加、关联高亮、抽取 getNodeSchema 复用）；editContainer/index.vue（模式守卫禁拖拽）；toolbar.vue（关联按钮+快捷键 L）；行为面板与画布双向高亮；多选（designer state 增加 selectedNodes）。
- **验收**：⚡N 角标点击切行为面板并展开；关联模式三步点选 + 快速关联气泡；Esc/空白/再点退出；拖拽被禁用；右键菜单直达正确面板。
- **风险**：徽标与拖拽/选中事件冲突（pointer-events 隔离 + stopPropagation）；关联遮罩随画布缩放。

### P3 · 联动/计算/事件总线模块 + 运行时增强（唯一触碰核心链路，建议 3-4 周）

- **目标**：完整闭环；运行时支持 enabled/delay/condition/emitEvent/vars/computed 求值。
- **涉及文件**：新增 rightSidebars/link/link.vue + FieldLinkEditor/ComputedFieldEditor/EventBusView，注册 link_view；types（FieldLink/ComputedField/ConditionGroup）；pageManager.ts（doActions 支持新字段 + emitEvent/onEvent/setVar/getVar 注册进 publicMethods 与公式上下文）；node.vue（事件级 enabled 透传）；builder.vue（computed 求值器 + links→fieldStates/on 编译注入）；utils 新增 linkCompiler.ts。
- **验收**：可视化创建"当 X 变化 → Y 隐藏/赋值"运行时生效，旧数据行为不变；计算字段多源依赖任一变化即重算；事件总线 A 广播 → B 动作链执行；生命周期全量人话命名。
- **风险**：doActions 是核心链路（新字段全部可选 + fail-safe）；computed 求值器按依赖字段白名单 watch（参考 node.vue:212-253 订阅优化），不做整树 deep watch；condition/links/computed 全部为纯 JSON DSL。

## 8. 明确"不做"清单

| # | 不做 | 理由 |
| --- | --- | --- |
| 1 | 画布节点连线图（端口拖拽拉线） | 表单元素无"端口"语义，视觉噪声大；键盘/读屏不可用；点选源→目标→气泡已覆盖 90% 场景 |
| 2 | 可视化流程编排引擎（BPMN/状态机） | 超出表单设计器边界，与"表单即 JSON"模型冲突；条件用 DSL 表单足够 |
| 3 | 第四种"动作语言" | 自定义函数继续用 JS，表达式用 FormulaEngine DSL，不引入新脚本方言 |
| 4 | 跨页面/跨表单编排 | 事件总线限定页面内；跨页面由宿主应用负责 |
| 5 | 组件间属性实时双向同步 | 双向同步易循环依赖；统一"事件驱动单向赋值"表达 |
| 6 | 任意方法的批量绑定 | 批量仅开放安全动作集（setValue/setAttr/启停用/删除） |
| 7 | 全量事件调试日志面板 | 用现有 console 输出 + 预览模式验证，后续单独立项 |
