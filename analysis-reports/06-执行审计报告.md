## 二、集成契约核对（a–f 逐项结论）

### a) compileLink 接线（关键项）—— ✅ 已接线（审计完成）

- **utils 导出链确认**：`compileLink` / `compileLinks` 定义于 packages/utils/src/schema/linkCompiler.ts:39/:123，经 schema/index.ts（`export * from './linkCompiler'`）→ utils/src/index.ts（`export * from './schema'`）对外可达；common/index.ts 补 `export * from './condition'`。
- **接线前状态**：FieldLinkEditor 处于「只写 links」回退态（文件头契约注释 + handleSave 内"运行时编译入口（WP-C 就绪后在此追加）"占位）。
- **接线实现**（FieldLinkEditor.vue）：
  - `resyncLinksToOn(schema)`：保存/启停用后把源元素 links 经 compileLinks 整体重编译写回 on[change]（保留无 linkId 的手工动作如快捷气泡/事件面板写入；停用规则不编译；目标不存在被过滤 fail-safe；无 on 且无动作时跳过写回避免 schema 噪音）。
  - `removeCompiledActionsFromOwner(ownerId, linkId)`：删除/编辑旧源清理按 linkId 从 on[change] 过滤。
  - 保存路径（handleSave）：编辑时先按 linkId 清理旧源 on[change] → 写 links → resyncLinksToOn(新源) → revoke.push('关联编辑')。
  - 删除路径（handleDelete）：removeLinkFromOwner + removeCompiledActionsFromOwner（按 linkId 过滤）→ revoke.push。
  - 启停用路径（handleToggle）：改 links.enabled 后 resyncLinksToOn（停用移除/启用重建）→ revoke.push。
- **运行时闭环**：编译产物为携带 linkId 的普通 ActionsModel（type:'component'，methodName setAttr/setValue，args JSON 串，condition=enabled），node.vue:369-380 在非设计态把 on[change] 绑定为组件 onChange → pageManager.doActions 执行（表达式值经 **isExpression** 分支求值）。setAttr hidden 经 node.vue:262 show 计算生效；disabled/readonly 经 getProps（:395-405）生效；setValue 经 node.vue:434 生效。
- 撤销一致性：links 与 on[change] 均写入同一 pageSchema 对象，revoke 差异快照原子覆盖两者。

   - builder.vue computed 求值器无单测（组件级，依赖 pageManager + isDesignMode 状态）——建议后续补充（P3-j 目前为代码级验证）。
2. **本轮裁剪项**（按 06-执行计划.md 第二部分，独立后续工作包）：
   - 内置右键菜单（仓库 contextMenu 为注入扩展点，入口已由工具栏按钮 + 角标 + 气泡覆盖）；
   - 多选批量（DesignerState.selectedNodes 独立工作包）；
   - 面板↔画布双向高亮联动（跨 core/panel-ui 通信机制）；
   - 右侧面板自动切换（手动切「关联与计算」页签）。
3. **已知风险**：
   - pluginManager.publicMethods 为模块级单例：多设计器实例下后创建的 pageManager 覆盖 emitEvent/onEvent/setVar/getVar 注册（pageManager.ts:539-540 已文档化，多实例场景需注意）。

   - computed 求值器每次重算 new FormulaEngine()（builder.vue:169）——AST 静态缓存下开销低，可提为模块级复用优化。
4. **eslint 基线**：69 条 no-explicit-any 告警为既有风格基线，未清零（本次改动未新增 error）。
5. **后续衔接**：P4 批次建议优先做多选批量 + 面板双向高亮 + 右键菜单，并补 FieldLinkEditor/computed 求值器的组件级测试。
