# 行为（事件与动作）配置

:::tip 行为配置说明「行为」面板（原「事件」面板）用于配置元素**能响应什么、要做什么**——即事件与动作链。您可以为某个事件（如「值变化时」）绑定一条或多条动作（如「把「金额」设置为 数量×单价」），并借助表达式插入器让动作参数动态取值。:::

## 行为面板

行为面板是设计器右侧边栏中的「行为」页，自上而下包含：搜索框、事件分组列表与空状态引导。

### 事件分组

事件按来源分为三类，首次打开默认展开「组件事件」与「页面级生命周期」，其余折叠：

- **⚡ 组件事件**：该组件自身可响应的操作，来自组件扩展注册的 `config.event`（如 `change`、`click`），展示为业务化命名（人话），缺省回退 `description`；
- **📦 页面级生命周期**：`aigenReady`（页面加载完成），整个页面所有组件渲染完成后触发一次；
- **🧩 组件级生命周期**：挂载 / 更新 / 卸载 / 错误 四个子分组，共 7 个事件，人话命名见下文 [生命周期人话命名表](#生命周期人话命名表)。

每组事件卡片展示：名称（人话）+ 描述（1 行解释）+ 右侧动作数徽标 + 展开箭头。

### 搜索

面板顶部提供搜索框，可按 **事件名 / 动作摘要 / 目标组件名** 过滤，快速定位到要查看或编辑的动作。

### 动作卡片（动作行）

每个事件下展开的动作列表，每条动作一行，支持：

- **拖拽排序**：拖拽把手调整动作执行顺序；
- **启停用**：开关切换该动作是否参与执行（`enabled` 字段，缺省视为启用），停用的动作行置灰；
- **动作摘要**：自动生成的人话摘要，例如「把『金额』设置为 数量×单价」「调用『合计』的 计算合计」「执行自定义函数 xxx」；
- **编辑 / 复制 / 删除**：复制会生成新的动作 `id` 并追加到同一事件的动作列表末尾；
- **更多**（高级折叠）：条件、延迟、备注等高级字段（P1 仅保存字段，P3 运行时生效）。

### 空状态模板

当元素一个动作都没有时，面板显示空状态引导，点击任一模板即可直达动作配置向导并预填：

- 点击时显示/隐藏其他元素
- 值变化时计算合计
- 页面加载时填充默认值

## 动作配置向导（四步）

点击事件下的「添加动作」或右键菜单「绑定事件…」打开动作配置抽屉（720px 右侧抽屉，与画布同屏），四步步骤条：`1 动作类型 → 2 目标组件 → 3 动作方法 → 4 参数配置`，可点击回跳，已填步骤打勾；编辑已有动作时直达已填步骤。

### 1. 动作类型

选择要创建的动作类型：

- **🧩 操作组件（推荐）**：调用其他元素的方法、设置值/属性/显隐；
- **⚙️ 执行函数**：执行自定义函数（页面脚本 `defineExpose` 暴露）或公共函数（插件注册的公共方法）；
- **📄 页面能力**（P3）：提交/重置表单、广播事件、读写全局变量。

### 2. 目标组件

通过三种方式选择目标组件（Tab 切换）：

- **画布点选**（默认）：移动鼠标在画布上预览高亮，点击选中目标元素；
- **组件树**：搜索框 + 组件树，树节点显示隐藏/禁用状态图标；
- **搜索**：按 label / id / 类型过滤，从结果列表中选择。

目标需为可操作组件；若目标组件没有可执行方法，步骤 3 会给出空态引导（改用 `setValue` / `setAttr`）。

### 3. 动作方法

展示目标组件全部可执行方法（来自 `config.action` 的 `describe` / `description` 说明），支持搜索：

| 方法       | 说明示例                                | 参数                  |
| ---------- | --------------------------------------- | --------------------- |
| `setValue` | 将目标元素的值设为指定内容              | 值                    |
| `setAttr`  | 修改目标元素的某个属性（如 `disabled`） | 属性名, 值            |
| `getValue` | 获取目标元素当前值                      | 无参数                |
| …          | 来自组件扩展 `config.action` 的其他方法 | 按 `argsConfigs` 渲染 |

### 4. 参数配置

按 `argsConfigs` 表单化渲染参数（常量 / 字段引用 / 公式三种输入方式），每个参数旁提供 **[fx] 表达式插入器**；下方「高级」折叠区可配置：条件（when 数量 > 0）、延迟（ms）、动作命名、备注。底部提供**实时预览**（设计态安全求值展示，不触发任何运行时事件）。

## 表达式插入器

点击任意参数旁的 [fx] 按钮弹出表达式插入器，三列布局：

- **左列**：表单字段列表（含字段人话 label）+ 内置函数库（每个函数带一句说明）；
- **中列**：公式编辑区（等宽字体），点击字段/函数即插入，字段引用自动补 `$formData.` 前缀；
- **右列**：**实时预览**（用当前表单模拟数据求值）+ 语法校验（错误红字）。

产出结果为 `{"__isExpression__": true, "content": "..."}` 并序列化进参数，与运行时 `doActions` 现有支持完全对齐。

### 字段引用

以 `$formData.字段名` 引用表单数据，例如：

```text
$formData.qty * $formData.price
```

除 `$formData` 外，还可在表达式中使用 `$event`（当前事件对象）与 `$vars`（全局变量）。

:::tip 事件参数引用事件触发时，原生参数会以数组形式注入 `$event`：`$event[0]` 为第一个参数、`$event[1]` 为第二个参数。例如「值变化时」（change）事件第一个参数就是组件的新值——用表达式 `$event[0]` 即可把新值传给动作。表达式插入器的字段列表顶部已提供「事件参数① / ②」快捷插入项。:::

### 内置函数表

| 函数        | 说明                    | 示例                           |
| ----------- | ----------------------- | ------------------------------ |
| `ABS`       | 取绝对值                | `ABS(-5)` → 5                  |
| `AVERAGE`   | 求平均值                | `AVERAGE(1, 2, 3)` → 2         |
| `IF`        | 条件判断，返回真/假分支 | `IF(数量 > 0, '有效', '无效')` |
| `MAX`       | 取最大值                | `MAX(1, 5, 3)` → 5             |
| `MIN`       | 取最小值                | `MIN(1, 5, 3)` → 1             |
| `MU_TO_SQM` | 亩转平方米（农业常用）  | `MU_TO_SQM(1.5)` → 1000.005    |
| `SUM`       | 求和                    | `SUM(1, 2, 3)` → 6             |

> 内置函数由 FormulaEngine 提供（jsep 解析），可在表达式中自由组合字段引用与函数。

## 示例：开关控制输入框禁用

目标：打开「开关」时禁用「输入框」，关闭时恢复可用。

1. 选中「开关」→ 右侧「行为」面板 → 事件组「组件事件」→ 事件「值变化时」→ 添加动作；
2. 动作向导：① 动作类型选「操作组件」→ ② 目标组件用「画布点选」选中「输入框」→ ③ 方法选「设置属性 setAttr」；
3. ④ 参数配置：属性选择 disabled，属性值点击 [fx] 打开表达式插入器，插入「事件参数①」得到 $event[0]（即开关切换后的新状态），保存；
4. 点击「预览」：打开开关 → 输入框禁用；关闭开关 → 输入框可用。

对应 schema 节选：

```json
{
  "on": {
    "change": [
      {
        "type": "component",
        "componentId": "input_9695",
        "methodName": "setAttr",
        "args": "[\"disabled\",{\"__isExpression__\":true,\"content\":\"$event[0]\"}]"
      }
    ]
  }
}
```

> 提示：属性值必须填写（直接值或表达式均可），留空会保存为 null 导致动作静默不生效。

## 生命周期人话命名表

与 [组件扩展 - 生命周期事件](../extensions/component.md) 保持一致。技术名仅在「高级/源码」模式展示：

| 技术名（旧事件名） | 业务化命名（人话） | 触发时机 | 典型用途 |
| --- | --- | --- | --- |
| `aigenReady` | 页面加载完成 | 首屏全部组件挂载后触发一次 | 初始化默认值、拉取首屏数据、初始跳转 |
| `vnodeMounted` | 组件挂载完成 | 当前组件完成首次渲染后触发 | 组件自身初始化、加载选项数据 |
| `vnodeBeforeMount` | 组件挂载前 | 组件即将渲染到页面之前 | 预置初始属性/状态 |
| `vnodeUpdated` | 组件更新完成 | 当前组件的属性或数据更新之后触发 | 值变化的后续处理（简单场景建议优先用对应业务事件，如 `change`） |
| `vnodeBeforeUpdate` | 组件更新前 | 更新发生之前 | 记录旧值、拦截更新 |
| `vnodeUnmounted` | 组件卸载完成 | 组件从页面移除后触发 | 清理定时器、解绑订阅 |
| `vnodeBeforeUnmount` | 组件卸载前 | 组件即将被移除之前 | 释放资源、确认离开 |
| `vnodeErrorCaptured` | 组件错误捕获 | 组件内部渲染或运行出错时 | 错误提示、降级显示 |

## 数据模型

### schema.on 结构

事件与动作绑定存放在元素的 `on` 字段中，结构为事件名到动作列表的映射，写入层保持该结构不变：

```ts
interface ComponentSchema {
  // 其他字段...
  on?: {
    [event: string]: ActionsModel[];
  };
}
```

```json
{
  "on": {
    "change": [
      {
        "id": "act_xxxxx",
        "type": "component",
        "componentId": "input_qty",
        "methodName": "setValue",
        "args": "[{\"__isExpression__\": true, \"content\": \"$formData.qty * $formData.price\"}]"
      }
    ]
  }
}
```

### ActionsModel 可选新字段

P1 阶段在 `ActionsModel` 上新增以下**可选字段**（均为可选、缺省兼容旧数据，不改变既有字段语义）：

| 字段 | 类型 | 说明 | 阶段 |
| --- | --- | --- | --- |
| `id` | `string` | 稳定身份：拖拽 key、复制、条件引用、日志定位 | P1（旧数据缺省，读取层补 UUID） |
| `name` | `string` | 动作命名（人话），用于摘要/搜索/下拉展示 | P1 |
| `remark` | `string` | 备注 | P1 |
| `enabled` | `boolean` | 启停用，缺省视为 `true`（undefined 视为启用，兼容旧数据） | P1 存储，P3 运行时生效 |
| `group` | `string` | 动作分组名（行为流分组） | P1 先存字段，P3 生效 |
| `delay` | `number` | 延迟执行毫秒数 | P1 存储，P3 运行时生效 |
| `condition` | `ConditionGroup` | 条件（纯 JSON DSL 对象而非函数——函数不可序列化），支持 AND/OR 组合与嵌套 | P1 存储，P3 运行时求值 |

:::warning 阶段说明以上新字段在 **P1 阶段仅做存储与展示**（`id`/`name`/`remark` 直接用于 UI；`enabled`/`group`/`delay`/`condition` 先存入 schema），**P3 阶段才在运行时生效**（`doActions` 对 `enabled === false` 跳过、`delay` 用 `setTimeout`、`condition` 求值）。:::

### 旧数据兼容（normalizeAction）

旧 schema 中的动作没有新增字段，读取层通过 `normalizeAction` 归一化兼容，**不迁移、不重写**旧数据（保存时才增量补齐 `id`）：

- 缺 `id` → 补 UUID；
- `enabled === undefined` → 视为 `true`；
- 其余字段透传。

```ts
import { normalizeActions } from '@aigen-designer/utils';

// 读取时归一化（缺 id 补 UUID、enabled 缺省视为 true）
const actions = normalizeActions(schema.on?.['change']);
```
