# 快捷键<span style="font-size:16px">v1.0.2</span>

:::tip 快捷键 `AigenDesigner` 提供了一些快捷键操作，帮助用户快速进行设计器操作，提升设计效率。

注：快捷键仅在设计器获得焦点时生效，在输入框（input、textarea）中输入时会自动忽略快捷键操作

:::

## 支持的快捷键

AigenDesigner 内置了以下快捷键操作：

### 组件操作

| 快捷键                 | 功能       | 说明                             |
| ---------------------- | ---------- | -------------------------------- |
| `Delete` / `Backspace` | 删除组件   | 删除当前选中的组件（根节点除外） |
| `Ctrl + C`             | 复制组件   | 将选中组件复制到剪贴板           |
| `Ctrl + V`             | 粘贴组件   | 将剪贴板中的组件粘贴到当前位置   |
| `Ctrl + X`             | 剪切组件   | 将选中组件剪切到剪贴板           |
| `Ctrl + D`             | 复制并粘贴 | 快速复制当前组件并立即粘贴       |

### 历史操作

| 快捷键                          | 功能 | 说明             |
| ------------------------------- | ---- | ---------------- |
| `Ctrl + Z`                      | 撤销 | 撤销上一步操作   |
| `Ctrl + Shift + Z` / `Ctrl + Y` | 重做 | 重做被撤销的操作 |

### 层级导航（新增）

| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| `Escape` / `ArrowLeft` / `Alt + ArrowUp` | 选择父级节点 | 选中当前组件的直接父级容器（若在根节点则取消选择） |
| `Enter` / `ArrowRight` / `Alt + ArrowDown` | 选择子级节点 | 进入当前容器组件的第一个子节点 |
| `Alt + 单击画布` | 穿透选择父级 | 跳过当前点击的叶子组件，直接选中直接父容器 |
| `原地再次单击` | 向上钻取 (Drill-Up) | 重复点击已被选中的组件，自动向外层父容器逐级提权 |

### 其他操作

| 快捷键     | 功能 | 说明             |
| ---------- | ---- | ---------------- |
| `Ctrl + S` | 保存 | 保存当前设计内容 |
